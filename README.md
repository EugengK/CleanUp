# CleanUp 🧹

AI 도구를 쓰면서 쌓인 부산물, 중복 파일, 안 쓰는 앱, 곳곳에 흩어진 AI 설치 흔적을 찾아 **안전하게** 정리하는 로컬 앱.
**macOS 전용**입니다. Python 표준 라이브러리만 사용합니다 (설치할 패키지 없음). 내 컴퓨터 안에서만 동작하고 아무것도 외부로 보내지 않습니다.

## 실행
```bash
python -m cleanup          # 브라우저가 열립니다 (http://127.0.0.1:8765)
python -m pytest tests     # 테스트 (pytest 필요)
```
Python 3.10+ 필요 (맥 기본 python3 가 낮으면 `brew install python`).

## 기능
| 탭 | 하는 일 |
|---|---|
| 불필요 파일 | 캐시·임시·백업·오래된 로그, `node_modules`/`.venv` 같은 재설치 가능 폴더, AI가 남긴 `SOMETHING_SUMMARY.md` 류 문서, N일 이상 안 쓴 큰 파일 |
| 중복 파일 | 크기 → 앞부분 해시 → 전체 SHA-256 으로 **내용이 완전히 같은** 파일만 묶음. 원본으로 보이는 1개는 보관 추천 |
| AI 흔적 | `~/.claude`, `~/.cursor`, `.ollama`, HF 캐시, Xcode DerivedData, Homebrew 캐시, `~/Library/Application Support/Claude` 등 + 프로젝트 안의 `CLAUDE.md`/`.cursor` 등 + AI를 쓴 프로젝트 폴더 |
| 안 쓰는 앱 | `/Applications`·`~/Applications` 앱의 Spotlight 마지막 실행일 (목록만 제공, 제거는 Finder에서 직접) |
| 보안 점검 | 코드/문서에 붙여넣은 API 키 의심 문자열, `.env`/개인키 파일, `invoice.pdf.exe` 같은 위장 파일, 방치된 설치 파일(.dmg/.pkg), 지운 앱이 남긴 `~/Library/LaunchAgents` 자동 실행 잔재 |
| 격리함 | 삭제한 항목 보관소. 복원 또는 영구 삭제 |

## 안전 설계
- 삭제 = **격리함으로 이동** (`~/.cleanup_app/quarantine`). 원래 위치가 기록되어 복원 가능. 영구 삭제는 별도 확인.
- 자동 선택은 '안전' 판정(캐시·임시파일)과 중복의 비-원본뿐. '확인 필요' 항목은 직접 체크해야 합니다.
- 홈 폴더 자체, 드라이브 루트, OS 시스템 폴더는 정리 불가.
- 서버는 127.0.0.1 전용 + 실행마다 바뀌는 토큰 + Host 검사. 서버는 **직전 스캔 결과에 있던 경로만** 이동시킵니다.
- 심볼릭 링크는 따라가지 않고, 하드링크는 중복으로 세지 않습니다.

## 한계 (정직하게)
- **개발은 리눅스에서 했고 맥에서는 아직 실행해 보지 못했습니다.** 파일 탐색·중복·격리 로직은 OS 중립이라 테스트로 검증했지만,
  `mdls`로 마지막 실행일을 읽는 부분과 `~/Library` 경로 목록은 실제 맥에서 확인이 필요합니다. 문제가 있으면 알려주세요.
- **보안 점검은 백신이 아닙니다.** 규칙 기반 후보일 뿐이며 오탐/미탐이 있습니다. 키가 유출됐다면 파일 삭제보다 **키 재발급**이 먼저입니다.
- `Library` 폴더는 기본적으로 '불필요 파일'·'중복' 검사에서 제외하고, 알려진 경로만 'AI 흔적'에서 보여줍니다 (앱 데이터를 잘못 지우는 사고 방지).
- 사진/음악 라이브러리(`.photoslibrary` 등) 내부는 건드리지 않습니다.
- 파일 '접근 시각(atime)'은 신뢰도가 낮아 "오래됨" 판단은 참고용입니다.
- AI 문서 판별(`ALL_CAPS_NAME.md` 등)은 이름 기반 추측입니다. 삭제 전 내용을 확인하세요.
- 맥 보호 장치(전체 디스크 접근 권한)로 일부 폴더(Desktop/Documents/Downloads 등)는 터미널에 권한이 없으면 읽히지 않을 수 있습니다.
  시스템 설정 > 개인정보 보호 및 보안 > 파일 및 폴더(또는 전체 디스크 접근)에서 터미널을 허용하세요.
